# Princeton COS 217: Introduction to Programming Systems

## Descriptions

- Offered by: Princeton
- Prerequisites: Proficiency in one programming language plus basic data structures and algorithms
- Programming Languages: C, ARM64 Assembly, Bash
- Difficulty: 🌟🌟🌟🌟
- Class Hour: 110 hours

COS 217 is Princeton University's core systems programming course. Its goal is to explain how programs written in a high-level language are compiled, assembled, linked, and ultimately executed by an operating system and processor. The course centers on C and the Unix/Linux environment, using ARM64 assembly to connect programs with compilers, operating systems, and hardware.

The public Fall 2023 archive includes course materials and seven programming assignments. The assignments begin with Unix tools and string modules, then progress through symbol tables, dynamic memory, assembly, processes, and build tools. It is excellent preparation for operating systems and compilers.

## Topics

- Linux, shell programming, and development tools
- C, pointers, structures, and dynamic memory
- Modular design, abstract objects, and data structures
- ARM64 assembly and machine language
- Processes, compilation, assembly, and linking
- Debugging, performance, and reliable software development
