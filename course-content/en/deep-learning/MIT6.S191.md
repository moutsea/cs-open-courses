# MIT 6.S191: Introduction to Deep Learning

## Course Overview

- University: MIT
- Prerequisites: Python programming and basic calculus or linear algebra
- Programming Language: Python, PyTorch, TensorFlow
- Course Difficulty: 🌟🌟🌟
- Estimated Study Hours: 40-60 hours

MIT 6.S191 is a compact introduction to deep-learning foundations and applications. It starts with neural networks, loss functions, backpropagation, and optimisation, then develops practical examples in computer vision, sequence modelling, generative models, and language models.

The course is a good first step before CS230, CS224n, or a specialised LLM course. Its lectures and lab-style materials are designed to get learners training useful models quickly while still explaining the core mathematics and implementation choices.
