# fast.ai: Practical Deep Learning for Coders

## Course Overview

- University: fast.ai
- Prerequisites: At least some programming experience, Python, and basic high-school mathematics
- Programming Language: Python
- Course Difficulty: 🌟🌟🌟
- Estimated Study Hours: 50+ hours

Practical Deep Learning for Coders is a project-first deep-learning course. It teaches learners to build useful models early, then opens up the ideas behind computer vision, natural-language processing, tabular data, recommendation systems, and deployment. The course uses modern Python tooling and encourages experimentation rather than waiting to finish a long theory sequence first.

It is a strong complement to MIT 6.S191 or a more mathematical machine-learning course. Learners who want to understand the foundations more deeply can follow it with fast.ai's second part, which studies papers and implements core ideas from scratch.
