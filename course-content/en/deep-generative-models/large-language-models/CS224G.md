# Stanford CS224G: Building and Scaling LLM Applications

## Course Overview

- University: Stanford University
- Prerequisites: Comfortable programming, basic machine learning or LLM knowledge, and interest in building software products
- Programming Language: Python, JavaScript or TypeScript
- Course Difficulty: 🌟🌟🌟🌟
- Estimated Study Hours: 80+ hours

Stanford CS224G is a project-based course about building production-ready applications with large language models. It covers the application layer that is easy to miss in model-focused courses: prompt and context engineering, retrieval-augmented generation, tools and agent loops, evaluation, reliability, multimodal and voice applications, deployment, observability, and product iteration.

The course is a good complement to CS336 or CMU 11-667. It does not try to teach every detail of pretraining; instead, it focuses on turning models into useful, testable, and maintainable products through hands-on projects.
