# Full Stack Deep Learning: LLM Bootcamp

## Course Overview

- University: Full Stack Deep Learning / UC Berkeley community
- Prerequisites: Comfortable Python, basic deep learning, and familiarity with software development
- Programming Language: Python
- Course Difficulty: 🌟🌟🌟🌟
- Estimated Study Hours: 60+ hours

Full Stack Deep Learning focuses on the engineering lifecycle around AI-powered products. The LLM Bootcamp covers model and GPU selection, prompt engineering, retrieval and tool use, LLMOps, evaluation, deployment, monitoring, and user experience. The broader course also connects these topics to data collection, training, and continual improvement.

It is best viewed as a practical bridge from a notebook experiment to a reliable application. Learners who have studied an LLM or deep-learning fundamentals course can use it to understand the operational decisions that appear after the first successful demo.
