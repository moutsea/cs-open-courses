# Princeton COS 318: Operating Systems

## Descriptions

- Offered by: Princeton
- Prerequisites: Systems programming and data structures; the official prerequisite is COS 217 and COS 226 or equivalent experience
- Programming Languages: C, x86 Assembly
- Difficulty: 🌟🌟🌟🌟🌟
- Class Hour: 140 hours

COS 318 is Princeton University's undergraduate operating systems course. It begins with processes, threads, and synchronization, then moves through CPU scheduling, virtual memory, file systems, reliability, virtual machines, and networking. The emphasis is on understanding the implementation tradeoffs behind operating-system abstractions.

Its centerpiece is a sequence of six projects. Starting with a bootloader, students progressively implement a non-preemptive kernel, preemptive scheduling, inter-process communication, virtual memory, and a file system. By the end, the projects form a small but functional operating-system kernel.

## Topics

- Processes, threads, and context switching
- Mutual exclusion, semaphores, condition variables, and concurrency
- CPU scheduling and process management
- Address translation, paging, and virtual memory
- File systems, caching, and reliability
- Virtual machine monitors and networking fundamentals

## Access

Lecture materials, the reading list, and all six project descriptions are directly accessible. Recordings and the university discussion forum are not public, so the course is best suited to learners who can study systems material and debug kernel code independently.
