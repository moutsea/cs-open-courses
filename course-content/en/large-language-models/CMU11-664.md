# CMU 11-664/763: Inference Algorithms for Language Modeling

## Course Overview

- University: Carnegie Mellon University
- Prerequisites: One of 11-411/611/711, 11-785, 10-401/601/701, 10-715, or 11-667; comfortable programming in Python with some language-model and NLP background
- Programming Language: Python
- Course Difficulty: 🌟🌟🌟🌟
- Estimated Study Hours: 130 hours

This graduate course focuses on what happens after a language model is trained: the inference process. It surveys decoding methods, reasoning-time techniques, tool use, and inference-time scaling, with an emphasis on implementing and measuring each method rather than only reading about it. The lectures also cover the systems side — batching, KV caching, speculative decoding, hardware limits, and deployment trade-offs.

Assessment is built around three implementation-heavy homeworks and a final shared task. Students implement sampling and beam search, reward-guided decoding and self-refinement, then build an inference server with batching, KV caching, and speculative decoding; off-the-shelf servers such as vLLM and SGLang are excluded from that assignment. The final submission is an API-based server evaluated under a fixed latency budget.
