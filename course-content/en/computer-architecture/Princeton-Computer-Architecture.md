# Princeton: Computer Architecture

## Descriptions

- Offered by: Princeton
- Prerequisites: Digital logic, data structures, and basic assembly language
- Programming Languages: Assembly
- Difficulty: 🌟🌟🌟🌟
- Class Hour: 50 hours

Taught by Princeton professor David Wentzlaff, this Coursera course presents the design of complex modern microprocessors. It begins with instruction-set architecture and microcode, then progresses through pipelining, data and control hazards, caches, memory systems, superscalar processors, and multicore architecture.

Rather than focusing on a single processor, the course develops general methods for evaluating and designing microarchitectures. Its problem sets build skills in performance analysis, pipeline reasoning, and memory-hierarchy calculations. It is best suited to learners who already know digital logic and want to continue into systems or processor design.

## Topics

- Instruction-set architecture, microarchitecture, and microcode
- Pipelining, structural hazards, data hazards, and control hazards
- Caches, virtual memory, and the memory hierarchy
- Superscalar and out-of-order execution and branch prediction
- Multicore processors and parallel architecture fundamentals
- Processor performance analysis and design tradeoffs
