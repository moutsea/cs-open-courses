# Princeton COS 126: Computer Science — An Interdisciplinary Approach

## Descriptions

- Offered by: Princeton
- Prerequisites: No prior programming experience; high-school mathematics is sufficient
- Programming Languages: Java
- Difficulty: 🌟🌟
- Class Hour: 80 hours

COS 126 is Princeton University's introductory computer science course. It teaches programming as a practical tool for solving problems in science, engineering, and everyday life. Starting with Java fundamentals, the course moves through functions and modules, object-oriented programming, basic data structures, algorithm analysis, and foundational ideas in the theory of computation.

The course has an unusually complete set of learning materials. Princeton's official Booksite provides lecture notes, code, exercises, and programming assignments, while the Coursera edition organizes the material as a self-paced online course. It is a strong starting point for COS 226, COS 217, and other Princeton core courses.

## Topics

- Java fundamentals, control flow, arrays, and input/output
- Functions, modular programming, and recursion
- Object-oriented programming and abstract data types
- Sorting, searching, and introductory algorithm analysis
- Applications of computer science in science and engineering
