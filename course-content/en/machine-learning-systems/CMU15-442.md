# CMU 15-442/642: Machine Learning Systems

## Descriptions

- Offered by: CMU
- Prerequisites: Intro to Computer Systems (e.g., 15-213), Intro to Deep Learning, Basic Math
- Programming Languages: Python, C++, CUDA (PTX), TIRx
- Difficulty: 🌟🌟🌟🌟🌟
- Class Hour: 100+ hours

A full-stack machine learning systems course covering automatic differentiation, modern GPU programming, distributed model training, LLM inference, and machine learning compiler abstractions. Its assignments include building an autodiff framework, implementing distributed training mechanisms, and optimizing an FP16 GEMM kernel for NVIDIA Blackwell hardware.
