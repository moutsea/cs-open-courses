# Princeton COS 126: Computer Science — An Interdisciplinary Approach

## 课程简介

- 所属大学：Princeton
- 先修要求：无需编程基础，高中数学即可
- 编程语言：Java
- 课程难度：🌟🌟
- 预计学时：80 小时

COS 126 是普林斯顿大学的计算机科学入门课，强调用编程解决科学、工程和日常问题。课程从 Java 基础开始，逐步覆盖函数与模块、面向对象编程、基础数据结构、算法分析以及计算理论，适合第一次系统学习编程的同学。

课程的优势是配套资源完整：官方 Booksite 提供讲义、代码、练习和编程作业，Coursera 版本则将内容组织为可以自定进度完成的在线课程。完成后可以继续学习 COS 226、COS 217 等普林斯顿核心课程。

## 主要内容

- Java 基础、控制流、数组和输入输出
- 函数、模块化编程和递归
- 面向对象编程与抽象数据类型
- 排序、搜索和基础算法分析
- 计算机科学在科学与工程中的应用
