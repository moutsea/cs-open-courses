# Princeton: Computer Architecture

## 课程简介

- 所属大学：Princeton
- 先修要求：数字逻辑、数据结构与基础汇编知识
- 编程语言：Assembly
- 课程难度：🌟🌟🌟🌟
- 预计学时：50 小时

这门 Princeton Coursera 课程由 David Wentzlaff 教授讲授，系统介绍现代复杂微处理器的设计。课程从指令集架构和微码开始，逐步进入流水线、数据与控制冒险、缓存、存储系统、超标量处理器以及多核架构。

课程重点不是使用某一种处理器，而是掌握评价和设计微架构的通用方法。大量问题集用于训练性能分析、流水线推导和存储层次计算能力，适合已经学过数字逻辑、希望继续深入系统或处理器设计的学习者。

## 主要内容

- 指令集架构、微架构与微码
- 流水线、结构冒险、数据冒险和控制冒险
- Cache、虚拟内存和存储层次
- 超标量、乱序执行和分支预测
- 多核处理器与并行架构基础
- 处理器性能分析与设计取舍
