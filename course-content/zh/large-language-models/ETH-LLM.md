# ETH Zürich：Large Language Models

## 课程简介

- 所属大学：ETH Zurich
- 先修要求：没有正式先修，但需要熟悉概率论、线性代数、计算复杂性以及机器学习
- 编程语言：Python
- 课程难度：🌟🌟🌟🌟🌟
- 预计学时：150 学时

ETH Zürich 2025 年春季的这门课从语言模型的形式化基础讲起，一路推到当前主流的系统与应用。前半程包括概率定义、n-gram 与循环语言模型、Transformer、Tokenizer 和文本生成；后半程进入迁移学习与参数高效微调、上下文学习与指令微调、多模态、检索增强生成、面向推理的强化学习、RLHF，以及安全与隐私。

这门课的特点是理论和实现都不偏废。学生要完成三次作业，其中一次偏理论、两次偏实践，期末考试成绩占一半。课程笔记公开，适合想弄懂 LLM 行为背后的「为什么」、而不满足于再学一个 API 教程的自学者。
