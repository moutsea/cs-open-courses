# CMU 11-664/763：Inference Algorithms for Language Modeling

## 课程简介

- 所属大学：Carnegie Mellon University
- 先修要求：11-411/611/711、11-785、10-401/601/701、10-715 或 11-667 中的一门；能用 Python 编程，并具备语言模型与 NLP 基础
- 编程语言：Python
- 课程难度：🌟🌟🌟🌟
- 预计学时：130 学时

这门研究生课关注模型训练完成之后发生的事：推理。课程系统梳理解码方法、推理阶段的推理与搜索、工具调用以及 inference-time scaling，重点不是读论文，而是把每类方法实现出来、测出差异。后半程会讲到系统侧：请求批处理、KV cache、投机解码、硬件瓶颈与部署取舍。

考核由三次实现量很大的作业和一个共享任务组成。作业依次实现采样与 beam search、奖励引导解码与自我修正，然后在不使用 vLLM、SGLang 等现成推理服务器的前提下，自己写一个带批处理、KV cache 和投机解码的推理服务。最终提交的是一个 API 推理服务器，由课程方在固定延迟预算下评测。
