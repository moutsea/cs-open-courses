# UC Berkeley CS294/194-196：Large Language Model Agents

## 课程简介

- 所属大学：University of California, Berkeley
- 先修要求：强烈建议先具备机器学习与深度学习经验，例如修过 CS182、CS188、CS189
- 编程语言：Python
- 课程难度：🌟🌟🌟
- 预计学时：100 学时

这门 2024 年秋季的系列讲座由 Dawn Song 主持，每周邀请工业界或学界的研究者主讲，把 LLM Agent 当作一个系统问题来讲。课程从 Agent 需要的能力出发，覆盖推理、规划与工具调用，再进入 Agent 基础设施、检索增强生成、代码生成、多模态与机器人 Agent、评测、隐私安全以及多 Agent 协作。讲者大多直接参与相关工作，因此内容比一般综述更贴近实际系统。

所有选课学生都须到场听课，每周提交阅读总结。选修 1 学分还须提交一篇总结一场讲座的文章；选修超过 1 学分则用实验作业和项目替代这篇文章。2 学分的项目须提交书面报告，可采用调研综述形式；3 至 4 学分的项目须通过代码与 LLM 交互，其中 4 学分要求有较大规模的实现。剪辑后的讲座视频公开，没注册伯克利也能跟着听，但项目反馈与评分只对选课学生开放。
