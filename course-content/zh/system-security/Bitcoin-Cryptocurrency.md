# Princeton: Bitcoin and Cryptocurrency Technologies

## 课程简介

- 所属大学：Princeton
- 先修要求：基础数据结构、概率和计算机网络知识；无需区块链基础
- 课程难度：🌟🌟🌟
- 预计学时：20 小时

这门课由普林斯顿大学 Arvind Narayanan 等教师开发，从技术原理而不是投资角度解释 Bitcoin 和加密货币。课程先介绍哈希函数、数字签名和分布式共识，再分析 Bitcoin 如何实现去中心化、交易与脚本如何工作，以及挖矿、匿名性、监管和替代加密货币等问题。

课程配套教材可以免费在线阅读，Coursera 页面提供按模块组织的视频、测验和作业。它适合希望理解区块链安全模型与系统设计的学习者，不要求事先购买或持有任何加密货币。

## 主要内容

- 密码学哈希、哈希指针和数字签名
- 分布式共识、工作量证明与激励机制
- Bitcoin 交易、脚本和区块链数据结构
- 挖矿、矿池与网络安全
- 匿名性、隐私、监管和替代加密货币
