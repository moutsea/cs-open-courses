# Princeton COS 318: Operating Systems

## 课程简介

- 所属大学：Princeton
- 先修要求：系统编程、数据结构与算法；官方要求 COS 217 与 COS 226 或同等基础
- 编程语言：C, x86 Assembly
- 课程难度：🌟🌟🌟🌟🌟
- 预计学时：140 小时

COS 318 是普林斯顿大学的本科操作系统课程。课程从进程、线程和同步讲起，继续深入 CPU 调度、虚拟内存、文件系统、可靠性、虚拟机与网络，强调理解操作系统抽象背后的实现取舍。

这门课最有价值的部分是 6 个递进式项目：从 Bootloader 开始，逐步实现非抢占式内核、抢占式调度、进程间通信、虚拟内存和文件系统。完成整套项目后，学习者会得到一个小型但真实可运行的操作系统内核。

## 主要内容

- 进程、线程与上下文切换
- 互斥、信号量、条件变量和并发控制
- CPU 调度与进程管理
- 地址转换、分页和虚拟内存
- 文件系统、缓存与可靠性
- 虚拟机监控器和网络基础
