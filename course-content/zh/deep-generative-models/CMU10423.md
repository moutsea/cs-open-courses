# CMU 10-423/623/723：生成式人工智能

## 课程简介

- 所属大学：Carnegie Mellon University
- 先修要求：机器学习、深度学习、概率论，以及扎实的 Python 或 PyTorch 基础
- 编程语言：Python、PyTorch
- 课程难度：🌟🌟🌟🌟
- 预计学时：100 学时以上

CMU 的生成式人工智能课程研究如何为文本、代码、图像和其他数据构建并扩展生成模型。课程把自回归语言模型和 Transformer 与变分方法、扩散模型、多模态生成、模型评估，以及大规模训练中的工程问题联系起来。

它很适合放在通用深度学习课和专门的 LLM 课程之间。作业和课程项目要求把数学思想实现成可运行的模型，因此最好先掌握反向传播、优化和常见神经网络架构。
