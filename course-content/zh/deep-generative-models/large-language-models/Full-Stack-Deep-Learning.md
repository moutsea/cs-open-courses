# Full Stack Deep Learning：LLM Bootcamp

## 课程简介

- 所属大学：Full Stack Deep Learning / UC Berkeley 社区
- 先修要求：熟悉 Python，了解基础深度学习，并有软件开发经验
- 编程语言：Python
- 课程难度：🌟🌟🌟🌟
- 预计学时：60 学时以上

Full Stack Deep Learning 关注 AI 产品从实验到上线的完整工程生命周期。LLM Bootcamp 涵盖模型和 GPU 选择、Prompt 工程、检索与工具调用、LLMOps、评估、部署、监控和用户体验；完整课程还会延伸到数据收集、训练和持续改进。

它适合作为「从 Notebook 到可靠应用」的实践桥梁。学完一门 LLM 或深度学习基础课后，可以用这门课理解第一次 Demo 成功之后还要面对的工程决策。
