# Hugging Face LLM Course

## 课程简介

- 所属大学：Hugging Face
- 先修要求：熟练掌握 Python，并了解基础机器学习或深度学习
- 编程语言：Python
- 课程难度：🌟🌟🌟
- 预计学时：60-80 学时

Hugging Face LLM Course 是一门以工具和代码为中心的自学课程，介绍现代自然语言处理和大语言模型。课程会带着学习者使用 Transformers、Datasets、Tokenizers、Accelerate 以及 Hugging Face Hub，从传统 NLP 基础逐步过渡到微调、数据集准备、模型分享和更高级的 LLM 工作流。

如果已经会 Python 和神经网络，但还没有真正跑通过开源模型工作流，这门课很实用。它能把理论课程里比较抽象的工具链、数据格式和评估流程落到具体代码上。
