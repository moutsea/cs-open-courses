# Princeton COS 217: Introduction to Programming Systems

## 课程简介

- 所属大学：Princeton
- 先修要求：熟悉至少一门编程语言、基础数据结构与算法
- 编程语言：C, ARM64 Assembly, Bash
- 课程难度：🌟🌟🌟🌟
- 预计学时：110 小时

COS 217 是普林斯顿大学的系统编程核心课，目标是让学生理解高级语言程序如何经过编译、汇编和链接，最终在操作系统与硬件上运行。课程以 C 和 Unix/Linux 开发环境为主，并通过 ARM64 汇编连接程序、编译器、操作系统和处理器之间的层次。

公开的 2023 秋季归档包含课程讲义和 7 个编程作业。作业从 Unix 工具与字符串模块开始，逐步进入符号表、动态内存、汇编、进程以及构建工具，适合在操作系统或编译原理之前补齐系统基础。

## 主要内容

- Linux、Shell 与常用开发工具
- C 语言、指针、结构体和动态内存
- 模块化设计、抽象对象和数据结构
- ARM64 汇编与机器语言
- 进程、编译、汇编和链接
- 调试、性能与可靠的软件开发习惯
