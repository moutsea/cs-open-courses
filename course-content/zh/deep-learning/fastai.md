# fast.ai：面向程序员的实用深度学习

## 课程简介

- 所属大学：fast.ai
- 先修要求：有一定编程经验，会 Python，掌握高中数学基础
- 编程语言：Python
- 课程难度：🌟🌟🌟
- 预计学时：50 学时以上

《Practical Deep Learning for Coders》是一门以项目为先的深度学习课程。它会先带着学习者训练出有用的模型，再逐步解释计算机视觉、自然语言处理、表格数据、推荐系统和部署等主题。课程使用现代 Python 工具，鼓励先动手实验，不必等到学完一长串理论才开始做项目。

它很适合与 MIT 6.S191 或偏数学的机器学习课程搭配。想进一步理解底层原理，可以接着学习 fast.ai Part 2，阅读论文并从零实现重要方法。
